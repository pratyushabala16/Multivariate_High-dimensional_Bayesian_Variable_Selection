# Multivariate_High-dimensional_Bayesian_Variable_Selection
Bayesian Variable Selection on Multivariate High-dimensional models assuming sparsity

* Posterior probability framework derived using an amalgamation of spike-and-slab prior and g-prior on covariate matrices.
* Simplified Shotgun Stochastic Search with Screening (S5) used for variable selection.
* Importance of selected covariates derived from MPI.
